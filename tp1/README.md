**Aya Saghraoui**

## Project Description
This repository contains the first assignment for the Operating Systems course (2026).
The objective is to set up the development environment and execute a Bash script 
capable of retrieving and displaying basic system information within a cloud 
environment (Killercoda / Google Colab).

The `sys_info.sh` script extracts the following data:

1. Operating System name and Linux kernel version.
2. The current logged-in user on the machine.
3. The current working directory path.

A screenshot of the final execution is included in the repository.

## How to Run the Script

Follow these simple steps to run the script in your Linux terminal or cloud environment:

**1. Make the script executable:**
```bash
chmod +x sys_info.sh
```

**2. Run the script:**
```bash
./sys_info.sh
```
